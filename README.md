# MP1
## Run
Run create logs: `go run . genlog -n 10`. With exact number of lines: `go run . genlog -n 10 -lines 1000`

Format Commands
``` bash
gofmt -l .      # list files
gofmt -d a.go   # show diff
gofmt -w a.go   # format and write back
gofmt -w .      # format all the files in the directory
```
